Обе записи увеличивают значение х на 5 и сохраняют результат в х. но есть разница в синтаксисе. в некоторых случаях оператор += автоматически выполняет приведение типов. х = х+ 5 выдаст ошибку компиляции, потому что результат сложения будет int и надо будет приводить к нужному типу.
Разница в порядке выполнения: х++ сначала в выражение передается текущее значение х, а затем х увеличивается на 1. ++х сначала увеличивается на 1, а затем новое значение передается в выражение. 
В результате оператора сравнения всегда получается логический тип данных - bool. результат принимает значение true или false.
"Короткое замыкание" оптимизирует вычисления логических выражений. Если результат известен по первой части, вторая часть не вычисляется. Если левый операнд равен false в операции &&, правый не проверяется, так как результат в любом случае будет false.
Приоритет операций: умножение и деление выполняются раньше сложения и вычитания. Сложение и вычитание выполняется слева направо. выражение 10 - 2* 3 + 4 / 2  1) 2 * 3 = 6  2) 4 / 2 = 2; 3) 10 - 6 = 4; 4) 4 + 2 =6.
Скобки ставят даже там, где они не обязательны, для улучшения читаемости кода и снижения вероятности ошибок. Проще понять логику выражения и порядок вычислений явно виден.логические выражения считаются быстрее.
